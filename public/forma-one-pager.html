Guardrails and governance for viax surfaces.

Forma is the umbrella name for the way AI composes viax applications: a coordinating skill maps schema to UXM components, a fixed set of skills carry the cross-cutting concerns no portal should reinvent, and every build emits a design.md so humans review the spec before code lands. The first proof is Modo. The second is the generic Revenue Motion portal.
v2 · May 2026

Problem & Target

Today

AI can produce any UI you ask for. That is the problem. Without a frame, every portal is a one-off — bespoke forms, inconsistent components, role visibility bolted on, localization deferred, security reasoned about per screen. Reuse is theatre. Each engagement starts the work over.

Target

AI builds with Forma — composing UXM components against schema, behind a fixed set of skills that handle the things no portal should reinvent. Every build emits a design.md — the human-reviewable contract for what got composed. Engagements compound. Customers extend on the same surfaces viax delivers on, in the JS framework of their choice.

Why this matters for delivery

Each engagement compounds instead of resetting. Customers extend on the same surfaces viax delivers on — there is no fork — and choose the JS framework that fits their stack. AI gets faster and less risky over time, because every new capability lands inside Forma’s skills or UXM’s library, not on a blank file. Modo is the proof: viax ships its own product on the same components we ask customers to compose theirs from.

Principles

Non-negotiables
  • Things are built with Forma, never on it.
  • UXM is the only place components are defined; Forma composes from it, never around it.
  • Skills replace bespoke plumbing — forms, security, visibility, i18n.
  • Brand identity, accessibility, and variant consistency are UXM’s job — never AI’s per-screen decision.
  • Customers customize tokens and add components; core components stay viax-owned.
  • Customers pick the JS framework for their surfaces; the component contract and skills are not.
  • Every Forma build emits a design.md — the spec is the artifact AI is judged on, before code lands.
